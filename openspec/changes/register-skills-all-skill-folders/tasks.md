## 1. Source resolution (design D1, D2)

- [ ] 1.1 RED→GREEN: the Claude-user scanner treats a child as a skill when it is a directory **or a symlink resolving to a directory** containing `SKILL.md`. It skips dangling symlinks, non-skill directories (e.g. `.obsidian`), root `.md` files, and `synced`. The candidate records the resolved `SKILL.md` path.
- [ ] 1.2 RED→GREEN: the synced scanner reads `~/.claude/skills/synced/*/<n>/SKILL.md` and yields key `anthropic-skills:<n>`.
- [ ] 1.3 RED→GREEN: the Pi scanners. `~/.pi/agent/skills` and `.pi/skills` use recursive skill-directory discovery (the walk stops at a skill directory, is depth-bounded, and guards cycles by resolved path) plus root `.md` files named by stem. `~/.agents/skills` and project `.agents/skills` (cwd and ancestors up to the git root) use the same recursion but ignore root `.md` files.
- [ ] 1.4 RED→GREEN: the plugin scanner reads `installed_plugins.json` v2 and `settings.json` `enabledPlugins`. It scans `<installPath>/skills/<n>/SKILL.md` only for plugins that are enabled, `user`-scoped (or `project`/`local` whose `projectPath` is the project root), and whose `installPath` exists. It never reads `plugins/cache` otherwise. A reserved plugin name (`pi`/`agents`/`project`/`anthropic-skills`) is skipped with a warning. An unreadable manifest yields no plugin candidates and no plugin scopes.
- [ ] 1.5 RED→GREEN: the project name probe. It returns the origin remote's last path segment without `.git`, else the git top-level basename, else the cwd basename. The git calls go through the injected Commander, and the existing `detectRepo` logic is reused rather than duplicated. A linked-worktree fixture resolves to the repository name.
- [ ] 1.6 RED→GREEN: `ResolveSkillSources(home, cwd, deps)` composes the scanners in precedence order. A harness is included only when `update`'s harness probe detects it (reuse `supportedHarnesses`/`detectHarnesses`; do not re-hardcode `.claude`/`.pi`). It returns the candidates and `ScannedScopes` exactly as D5 defines them, including: a project scope only when cwd has a project skill directory, a disabled plugin not scanned, and an uninstalled plugin scanned.
