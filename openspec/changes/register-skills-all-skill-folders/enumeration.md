# Doc-surface enumeration: register-skills-all-skill-folders

The invariant that changes is **what registration's scanned set is**. Before this change, it was engram's own skills: `agent-instructions/skills` for update, and `~/.claude/engram/skills` for standalone (`8a672df5`). After it, the set is every default skill **and command** folder: Claude user skills and commands; claude.ai-synced skills; Pi user and agents skills; Pi `settings.json` skill paths and packages; enabled plugin skills and commands; and project-local Claude sources plus trusted Pi sources. Identity changes with it: `skill-<name>` becomes a source-qualified key (with a `cmd` segment for commands; `project:<owner>/<repo>:…`) and a slug derived from that key, with `skill_key`/`skill_source` recorded on the note.
