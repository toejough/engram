# Doc-surface enumeration: register-skills-all-skill-folders

The invariant that changes is **what registration's scanned set is**. Before this change, it was engram's own skills: `agent-instructions/skills` for update, and `~/.claude/engram/skills` for standalone (`8a672df5`). After it, the set is every default skill folder: Claude user, synced, Pi user and agents, enabled plugins, and project-local. Identity changes with it, from `skill-<name>` to a skill key and derived slug, with `skill_key`/`skill_source` recorded on the note.
