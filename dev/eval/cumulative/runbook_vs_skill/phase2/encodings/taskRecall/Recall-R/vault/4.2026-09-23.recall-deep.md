`recall-deep` is the full recall pass — all 10 Step-1 phrases and the write side. It both *applies* memory to this decision **and** *grows the vault* (crystallizes, persists synthesis). Use it when the decision is weighty or irreversible, when you want the pass to also learn, or when in doubt (absent any mode signal, default to `deep`).

Run [[1.2026-09-23.recall-core]] in full (10 phrases), then [[2.2026-09-23.recall-write-extension]] for both the per-cluster write actions (Step 2.5C, as each cluster is judged) and the Step 4 persist (after the closing synthesis).

## When you should have started here instead of `recall-glance`

If the ask sounded like a "quick check" but the decision actually turns on **honoring a standard that surfaced only in Channel 2 (recent activity)** — a "use X going forward" / "the new convention is Y" item, never itself a matched vault note — that is exactly [[3.2026-09-23.recall-glance]]'s C5 escalation case (#661: glance honors it 0/5, deep 4/5). A glance pass that skipped this note is silently under-applying memory: it will surface the item but never elevate it to a requirement, because the write side (and the deliberate "is this load-bearing" check) never runs. If you find yourself mid-`recall-glance` realizing this is the case, switch to this note rather than finishing glance's shorter pass.

More generally, prefer `recall-deep` over `recall-glance` whenever: the decision is weighty or irreversible, you want the pass to grow the vault (crystallize a new lesson, persist a synthesis conclusion), or you are not sure which rung applies.
