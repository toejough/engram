`recall-glance` is the cheap, read-only-with-respect-to-vault-knowledge rung of recall — for firing often. Run [[1.2026-09-23.recall-core]] with **~3 phrases** (not 10). Activation (Step 2.7) still bumps the used-notes recency metadata — that is kept, not a knowledge write. Stop after [[1.2026-09-23.recall-core]]'s Step 3.5: do NOT run [[2.2026-09-23.recall-write-extension]] — no `engram amend`, no `engram learn`, no persisted synthesis. Glance *applies* memory to this decision; it does **not** grow the vault's knowledge.

## Escalate to `recall-deep` for recency-channel standards (C5)

Glance reliably *surfaces* a recent-activity (Channel 2) item but does **not** elevate it to a requirement — measured: glance honors a recent-channel standard **0/5** where deep honors it **4/5** (#661 full-bars). So if your decision turns on **honoring a standard that surfaced in the recent-activity channel** (a "use X going forward" / "the new convention is Y" item in Channel 2), **switch to [[4.2026-09-23.recall-deep]]** before producing [[1.2026-09-23.recall-core]]'s Step 3 synthesis. Glance is validated as deep-equivalent only for applying conventions (C3), recency supersession within the matched set (C4i, via Step 2.5B), and abduction/synthesis (C6) — none of those need escalation.

Escalating means: continue exactly where you are, but treat the rest of this pass as `recall-deep` from that point forward — generate the full 10 phrases only if you re-query, run [[2.2026-09-23.recall-write-extension]] once the closing synthesis is ready, and follow [[4.2026-09-23.recall-deep]]'s own note for what that adds.
