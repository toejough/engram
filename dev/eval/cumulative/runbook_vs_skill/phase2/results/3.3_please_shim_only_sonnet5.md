## Why 3.1 passed but the trial failed

3.1 used situation-shaped phrases that already say "driving a user's multi-step ask end-to-end" (top rank 0.793). Real agents abstract the task's own content into the second phrase, so retrieval depends on the fixture text signalling "please" workflow. The shim tells the agent to write phrases in the "verb-ing object in context" form of the request, which here is the rename, not the please ceremony. The user-facing risk is real: a `/please` ask whose content is a concrete task may not surface the top runbook.
