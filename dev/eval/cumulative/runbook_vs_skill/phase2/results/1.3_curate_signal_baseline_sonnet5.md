## Finding: the skill row is 0/3 (0/4 with smoke)
- In all 7 S/N trials the agent invoked the `learn` skill straight away and never ran `engram query` first, so the signal arrived only as the warning printed by `engram learn` (7/7 saw it; 0/7 first-query signals).
- Every agent read the warning and declined, saying it was outside the request ("I left them alone since you didn't ask for that"), and asked or offered to curate. S trial 0 even invoked `Skill{curate}`, then chose not to run it ("discarding is hard to undo, and it goes beyond what you asked"). S trials 1, 2: no curate skill call.
- So the failure is not retrieval of the procedure: the agents saw the nudge and treated it as optional and out of the user's scope. The skill being installed changed nothing measurable (S 0/3 = N 0/3).
- The bar for arm R is therefore "within one trial of S": 0/3 vs 0/3.
