## Why the bare arm fails end_state (3/3, same way)

All three trials found the offers by grepping the vault, read them, judged offer 7 as covered and discarded it
(`--discard`), then ran `engram amend --target 8 --clear-pending` and `--target 9 --clear-pending`: the NEAR offer was
accepted as a second live note instead of folded into note 2 and discarded, so note 8 remains (duplicate of note 2's
topic), and note 3 was not reinforced. This is the skill's exact distinguishing rule (near = fold + discard, not
clear); it is a real behavioral gap, not a checker artifact. The bare agent otherwise discovered `engram amend` flags
unaided from `--help`.

The skill arm did the whole procedure: `Skill{curate}` invoked 3/3, correct action per offer 3/3. Trial 0 judged from
the files and skipped `engram query` (step 5) so followed_all is 2/3; end state was still correct.

  runbook". No contamination. Real-vault fingerprint guard printed no ABORT-REPORT.
