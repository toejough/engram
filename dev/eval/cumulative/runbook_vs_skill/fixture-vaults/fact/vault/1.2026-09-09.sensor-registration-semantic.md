The sensor registration procedure in telemetry systems involves six ordered operations:

1. Registry modification: Add a new entry to lib/sensors/registry.txt using tab-separated format with sensor identifier, version, name, and date.

2. Codegen execution: Run the codegen script (python3 scripts/sensors.py) to generate or update type definitions from the registry.

3. Migration creation: Create a migration file with naming pattern NNNN_sensor_<name>.go containing func init() that registers the sensor with the runtime.

4. Changelog update: Add an entry to TELEMETRY_CHANGELOG.log with timestamp, operator name, and sensor registration details in [YYYY-MM-DD HH:MM:SS] format.

5. Change staging: Verify all changes are prepared for commit without yet committing to the version control system.

6. Validation: Run make validate to verify all artifacts exist, have correct formats, and are in consistent state.
