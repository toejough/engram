## 855b14 A slow step is waited for, a stalled one is not

With no time bound before a [prompt](../793_automatic-memory/793a_product-spec.md#793a1a-terms) reaches the [agent](../793_automatic-memory/793a_product-spec.md#793a1a-terms), a step that is only slow is waited for ([855a3c 793a2d Never in the way](./855a_product-spec.md#855a3c-modified-793a2d-never-in-the-way)). A step that never answers cannot hold the prompt forever, and the host puts no ceiling on it: its type definitions (`claude-code.d.ts`, bundled with Claude Code 2.1.301 under `/private/tmp/claude-501/bundled-skills/2.1.301/e2ebd773aa00aeae2764ffb5641f2a63/plugin-authoring/types/`) give a hook a budget of `10_000` milliseconds (line 5250) but say "Each bounds the hook's OWN time: the clock stops while a `next(e)` call or any `$` call of the hook's is in flight" (line 5234), `timeoutMs` of a model call has "default none" (line 6365), and a command runs 30 seconds by default, ten minutes at most (line 3592). So the bound is a liveness bound of 2 minutes, far above any normal judgement: a judgement or delivery with no answer by then is stepped aside, delivers nothing and is shown as a failure. It is a liveness bound and not a latency target. Rejected: holding until the user interrupts; a host ceiling, which does not exist for these calls. Decided by: Owner (2026-10-18), option (b) of [855c1 How long may a judgement or delivery run before it is given up?](./855c_open-questions.md#855c1-how-long-may-a-judgement-or-delivery-run-before-it-is-given-up).

## 855b30 Every tool call of the main loop is judged, one at a time

The owner wants recall "as often as possible" ([855b23 Recall runs at the points the host offers](#855b23-recall-runs-at-the-points-the-host-offers)), so each tool call about to run, each that failed and each batch is a cue, judged by the cheap tier, one at a time for a [session](../../GLOSSARY.md#session) because the host may run the events of parallel calls at once ([855d1a Verified host facts](855d_technical-spec.md#855d1a-verified-host-facts)). That adds a model call to every tool call; time is "an optimization for later" ([855b4 No time bound before a prompt reaches the agent](#855b4-no-time-bound-before-a-prompt-reaches-the-agent)), and the time added is measured ([855d7a Hypotheses and their measurements](855d_technical-spec.md#855d7a-added-hypotheses-and-their-measurements)). Rejected: a filter of the tools judged, which is an optimization without a measurement. Decided by: Author (default; owner may override).

## 855b31 Placement is skipped without a seen note, and an unusable one is ignored

The placement call is not made when the [session](../../GLOSSARY.md#session) has seen no [note](../../GLOSSARY.md#permanent-note), since every lesson is then placed at the top and ties nothing ([855b16 Placement is the learn skill's ordered test](#855b16-placement-is-the-learn-skills-ordered-test)); a target or a superseded note that is not a seen note, and a reply that cannot be read, are ignored and the lessons are written at the top, the unreadable reply recorded as skipped so that the user is told. Rejected: failing the whole capture for a bad placement, which loses lessons that are whole. Decided by: Author (default; owner may override).

## 855b32 Candidates are judged one by one, and the session's own transcript is not a candidate

The [recall skill](../../GLOSSARY.md#recall-skill) judges a cluster of the matched [notes](../../GLOSSARY.md#permanent-note) and chunks; the automatic channel judges each candidate (covered, near, evidence or unrelated, and the newer of two that conflict), and at deep depth names the lessons the evidence shows that no candidate states. The sweep of [793d2c Conversation sweep flow](../793_automatic-memory/793d_technical-spec.md#793d2c-conversation-sweep-flow) indexes the live conversation after every [turn](../793_automatic-memory/793a_product-spec.md#793a1a-terms), so a chunk of the [session](../../GLOSSARY.md#session)'s own [transcript](../../GLOSSARY.md#transcript) is left out: the [agent](../793_automatic-memory/793a_product-spec.md#793a1a-terms) holds it. Rejected: clusters, which would carry the whole clustering through the carry for no verdict the candidates do not give. Decided by: Author (default; owner may override).

## 855b33 Excerpts are cut to 400 and 600 characters

A candidate is a line of at most 400 characters in the candidate request, as a [note](../../GLOSSARY.md#permanent-note) is in the request of [793d4g Judging a turn](../793_automatic-memory/793d_technical-spec.md#793d4g-judging-a-turn); a delivered passage is cut to 600 characters, more than a note line because a passage is a stretch of conversation. Both are values of the design and not measurements. Decided by: Author (default; owner may override).

## 855b34 An amend is a write, and a parent note is never amended

A [note](../../GLOSSARY.md#permanent-note) a deep delivery amends is recorded as written with its file name, so the user sees which notes [automatic memory](../793_automatic-memory/793a_product-spec.md#793a1a-terms) changed; the [recall skill](../../GLOSSARY.md#recall-skill)'s rule holds, so a note from the parent [vault](../../GLOSSARY.md#vault) and a pending copy are never amended, and each is recorded as skipped. Rejected: not recording amends, which leaves the vault changing unseen. Decided by: Author (default; owner may override).
