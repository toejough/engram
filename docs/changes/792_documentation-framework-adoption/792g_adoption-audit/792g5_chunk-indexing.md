# 792g5 chunk-indexing - Adoption Audit

Audit of [792a5 chunk-indexing](../792a_product-spec.md#792a5-added-chunk-indexing) and the [792b](../792b_technical-spec.md) requirements that support it, against the code at `dd2bd9e2` and a binary built from it, run on temporary vaults and chunk indexes (`ENGRAM_VAULT_PATH`, `ENGRAM_CHUNKS_DIR`, `HOME` and `XDG_DATA_HOME` all pointed at temporary directories).

Summary: most of the section matches the code, including every message the prune modes print. One sentence was corrected (792a5h: oversized sections are split by packing whole lines, not on paragraph boundaries). Five code problems were found and filed: #799 (zero-chunk sources re-read every run), #800 (relative source paths recorded as given), #801 (a `.git` file is not a repository marker), #802 (tool calls with block-list results dropped) and #803 (two stale texts). Cross-run duplicates are the existing #771. Nothing here is covered by #795 or #796. #802 and #803 are filed against behavior the spec states correctly or does not state, so their rows read `match`.
