# 792g14 recall - Adoption Audit

Audit of [792a14 recall](../792a_product-spec.md#792a14-added-recall) and the [792b](../792b_technical-spec.md) requirements that back its scenarios. Method: read the shipped `agent-instructions/skills/recall/SKILL.md` and its `tests/README.md` against every requirement and scenario, then ran the binary commands the skill names (`ingest`, `query --lazy-chunks`, `show-chunk`, `activate`, `amend`, `learn`) on a temp vault and chunk index and compared the payload with the skill's description of it. Line numbers (L..) are in that SKILL.md unless a file is named. Binary runs used a binary built from this tree (`go build -o /tmp/<x>/engram ./cmd/engram`) with HOME, XDG and `ENGRAM_VAULT_PATH`/`ENGRAM_CHUNKS_DIR` pointed at temp directories.

- 792b counts: 8 `match`.
- Doc fixes: none in the 792a14 section. - Code problems: #817 (filed): `agent-instructions/skills/recall/tests/baseline-multi-query.md` and its row in `tests/README.md` still lock 5-15 phrases, batched `activated: true` activation and `engram show` for candidates; 792d111 already noted the divergence and the baseline was left unedited. - Unclear: none.
