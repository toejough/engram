# 792g17 route - Adoption Audit

Audit of [792a17 route](../792a_product-spec.md#792a17-added-route) and the [792b](../792b_technical-spec.md) requirements that back its scenarios. Method: read the shipped `agent-instructions/skills/route/SKILL.md`, `price-table.md` and `tests/README.md` against every requirement and scenario, then ran the binary commands the skill names (`learn fact` with tags, `query`, `amend --object`, `count --group-by tags`) on a temp vault. Line numbers (L..) are in that SKILL.md unless a file is named. Binary runs used a binary built from this tree (`go build -o /tmp/<x>/engram ./cmd/engram`) with HOME, XDG and `ENGRAM_VAULT_PATH`/`ENGRAM_CHUNKS_DIR` pointed at temp directories.
