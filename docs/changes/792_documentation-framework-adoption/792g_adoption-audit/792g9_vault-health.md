# 792g9 vault-health - Adoption Audit

Audit of [792a9 vault-health](../792a_product-spec.md#792a9-added-vault-health) and the [792b](../792b_technical-spec.md) requirements whose `Supports:` lines cite its scenarios ([792b26 vault-invariant-checker](../792b_technical-spec.md#792b26-added-vault-invariant-checker), the census, selection, run and CRLF requirements of [792b10 embedding-sidecar](../792b_technical-spec.md#792b10-added-embedding-sidecar), and [792b13c6 Unresolved links](../792b_technical-spec.md#792b13c6-unresolved-links)). Method: read internal/cli/check.go, internal/cli/embed.go, internal/embed/state.go and internal/embed/sidecar.go, then ran every scenario on a binary built from this tree against temp vaults, with HOME, XDG, `ENGRAM_CHUNKS_DIR` and `ENGRAM_VAULT_PATH` pointed at temp dirs.

Summary: the specs describe the code. No spec text needed editing. Two code problems were filed: the G0 bare-ID test is lowercase-ASCII only (#810), and the legacy G2 orphan check was intended but never built (#811). The legacy E1 was dropped on purpose (a missing sidecar is the S1 WARN). Two README lines on `embed status` and `embed apply` and four Go comments were stale and are fixed. The creation of a missing vault by `check` and `embed` is replaced by [795a Vault Init Command - Product Spec](../../795_vault-init-command/795a_product-spec.md), and the starter README by [796a Controlled Vault README - Product Spec](../../796_controlled-vault-readme/796a_product-spec.md).
